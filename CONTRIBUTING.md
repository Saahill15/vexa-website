# Contributing

Clone this application and create a branch from `main`. Work in your local copy. Use the README's preview command; it requires no production credentials.

Return a pull request with the purpose, changed files, checks and desktop/mobile screenshots for presentation changes. Commits and pushes to your own feature branch are the normal review workflow. The owner reviews/merges and performs releases. Do not push directly to `main`, change a release branch or run a deployment for a presentation task.

Sahil's current website task covers animations, spacing/alignment, responsive layout and footer presentation. Flag content and team-role edits first. Authentication, APIs, access permissions, database/schema, pricing logic and deployment are outside that task unless separately assigned. The website task does not automatically authorize OS or Valuate changes.

Never commit filled `.env` files, private keys, account tokens, local/live databases, logs containing user data or company documents. `.env.example` lists empty configuration names. Production credentials and runtime data are separate from application source.

Historical documents under `docs/archive/` explain earlier work; start with the current README and architecture/deployment guides. Avoid reintroducing retired payment features, old copy or obsolete paths from an archive.
